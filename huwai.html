一、指南指引

适用范围运动户外男装 商品上架后长期无销量或销量极低的自查排查
适用对象Temu平台运动男装品类全托管商家（常规免审组+常规印花组）
这份指南干啥用的帮助商家按标准化流程逐项排查无动销原因，快速定位问题并采取纠正措施

1.1 指南的作用

这份指南是帮Temu全托运动户外男装商家一步步查清楚「为什么我的货卖不动」。东西上架了但一直没人买，照着这个一步步查，找到原因然后改过来，让货能卖出去。

1.2 什么时候用

碰到下面这些情况，就照着查一遍：

  • 商品上架超过7天，累计销量为0，曝光极少
  • 商品日均销量明显低于同店铺其他正常动销商品
  • 商品此前有动销，但突然连续7天以上无销量
  • 商品参与平台活动后，活动期间仍无销量
  • 商家批量上架男装商品后，整体有销量的SKU占比低于预期

1.3 术语解释

术语解释
无动销商品上架后一段时间内（通常7天以上）无任何订单产生，或销量极低
生命周期状态商品在平台上的状态，包括在售、审版中、已下架、已冻结等
加站将商品/SKU加入目标销售站点的操作，加站后商品才能在该站点展示和售卖
在架SKU在站点上处于可售卖状态，买家可以看到并下单
有销量的SKU占比有销量的SKU数 / 总SKU数 * 100%，反映商品销售活跃度
价格区间某一品类商品在平台上的主流售价区间，通常按销量分布确定
商品信息评分平台对商品标题、属性、图片、描述等信息填得全不全和质量的综合评分

二、查询定位

请按以下8个维度依次排查。前4个维度为「硬伤问题（东西卖不了）」（直接导致商品无法售卖），后4个维度为「改进问题（能卖但卖不好）」（影响销量但商品仍可售卖）。建议优先排查硬伤问题（东西卖不了）。

序号类型查什么要确认啥
1硬伤商品状态商品是否处于「在售」状态？是否被下架/冻结/处罚？
2硬伤SKU在架与加站状态各SKU是否已加入目标站点？是否在架可售？
3硬伤查有没有被处罚商品是否存在违规处罚导致被不让你卖、排名往后排或下架？
4硬伤查有没有库存商品是否有可用库存？是否断货导致无法售卖？
5改进商品图片和信息好不好主图/详情图质量是否过关？标题/属性/描述是否完善？
6改进供货价贵不贵、价格有没有竞争力前台售价是否偏高？供货价是否有优化空间？是否被平台选入活动？
7改进有没有参加活动、广告？是否被平台选入活动？是否有足够曝光和流量？
8改进评价好不好、退货多不多商品是否有差评？退货率是否偏高？是否影响转化？
⚠️ 注意

1. 先查硬伤再查改进：先排查1-4项硬伤问题（东西卖不了），确认商品能正常售卖后，再排查5-8项改进问题（能卖但卖不好）。

2. 全SKU覆盖：排查时需覆盖商品下所有SKU，不能只查主SKU。

3. 全站点覆盖：确认商品在每个目标站点的状态，不能只看一个站点。

4. 写下来记好：每项排查结果需记录在第四章的记录表中，便于后续跟踪。

三、商家运营排查步骤

步骤1：查商品状态对不对

要查什么：看看你的商品现在是不是正常「在售」状态。如果状态不对，买家根本看不到你的东西，更别说买了。

1.1 自查操作路径

操作步骤详细说明
Step 1：登录后台登录Temu商家后台
确认登录账号有商品管理权限
Step 2：进入商品管理导航至「商品管理」-「商品生命周期」页面
页面显示所有商品的生命周期状态列表
Step 3：搜索目标商品在搜索框输入商品ID（Goods ID / SPU ID / SKC ID）
也可通过店铺ID筛选店铺下所有商品
建议一次查询多个商品ID，批量排查
Step 4：查看生命周期状态查看商品的「生命周期状态」-待办
Step 5：查看代办信息1. 商品生命周期状态 — 确认商品是否处于"在售"状态，是否被下架、冻结、审版未通过等
2. SKU在架状态 — 确认各SKU是否已加入站点、是否在架可售
3. 违规处罚 — 商品是否存在违规处罚导致被限制售卖或下架
4. 库存情况 — 商品是否有可用库存，是否断货
5. 流量待提升 — 是否有低价同款抢流量

1.2 状态判断标准与处理方案

生命周期状态是不是卖不了可能原因处理方案
在售否 - 正常状态正常，继续下一步排查进入步骤2排查SKU状态
违规待整改是 - 违规站点卖不了看下面治理驳回原因详解看治理驳回能不能捞，能捞可以自行提交申诉，不能确定联系对接运营
流量待提升否 - 部分站点屏蔽尺码站内有同款且同款低价1. 生命周期查看同款详情，确实为同款，辛苦看下能否跟价（降供或报活动均能解除），能跟尽快操作尽早解除
2. 生命周期查看同款详情，误识别为同款，【同款不准】先自行完善理由申诉，申诉被驳回确有疑问的，发【spu+商品不同点】反馈对接运营直接处理
3. 看不到同款详情，请截图+spu发我核实情况
已下架是 - 卖不了商家主动下架 / 平台强制下架（违规/质量不合格）确认下架原因 → 修正问题 → 重新申请上架
草稿/未提交是 - 卖不了商品信息未填写完整或未提交审核完善商品信息 → 提交审版

1.3 男装商品常见治理驳回原因详解

驳回类型具体表现修改方案
图片问题主图有牛皮癣/水印/文字遮挡；图片模糊；图片比例不符；图片含违规内容重新拍摄/修图，确保白底或场景图清晰无遮挡，符合平台图片规范
属性缺失材质/版型/领型/袖长/适用季节等关键属性未填写该填的都填上，能填的也尽量填，填得越全越好
资质问题缺少品牌授权/质检报告/成分检测报告等准备并上传相关资质文件，确保品牌授权链路完整
尺码问题未提供尺码表/尺码表不完整/尺码数据有误提供完整尺码表（含肩宽/胸围/衣长/袖长等），建议增加身高体重参考
描述不符商品描述与图片/属性不一致（如描述纯棉但属性写聚酯纤维）标题、图片、属性里写的内容要对得上，别一个地方写纯棉另一个地方写涤纶

步骤2：查SKU有没有上架、有没有加到站点

要查什么：看看每个SKU（不同颜色/尺码）是不是都加到了你要卖的站点、是不是都在架能卖。有时候商品整体是在售的，但某个颜色或尺码没加站或者下架了，那个SKU就卖不了。

2.1 自查操作路径

操作步骤详细说明
Step 1：进入商品详情在「商品生命周期」页面，点击目标商品进入详情页
找到「SKU信息」栏目
Step 2：查看SKU列表页面会展示该商品下所有SKU的列表
记录每个SKU ID及其对应的状态信息
Step 3：检查在架状态查看每个SKU的「在架状态」字段
状态应为「在架」才可被买家购买
若显示「不在架」或「已下架」，需进一步排查原因
Step 4：检查加站情况查看每个SKU的「已加入站点」字段
确认目标销售站点是否在已加站列表中
若目标站点未加站，SKU将无法在该站点展示和售卖
Step 5：批量排查若有大量商品需排查，建议按店铺维度批量查询
统计未加站/不在架的SKU数量和占比

2.2 判断标准与处理方案

SKU状态是不是卖不了可能原因处理方案
已加站 + 在架否 - 正常SKU状态正常，可正常售卖进入步骤3排查违规处罚
未加站是 - 卖不了未提交加站申请 / 加站审核未通过 / 加站后被移除在商品管理页面提交加站申请，确认选择正确站点；若审核未通过，查看原因并修正后重新提交
已加站但不在架是 - 卖不了SKU被单独下架 / 库存为0 / 价格异常 / 违规处罚依次排查：库存是否有货 → 价格是否正常 → 是否有违规处罚 → 修正后重新上架SKU
部分站点未加站部分卖不了SKU只加入了部分站点，其他站点无法售卖确认目标销售站点清单，对未加站站点提交加站申请
📌 户外男装品类加站注意这几条

1. 商品通常需要加入多个站点（如美国站、欧洲站等），确认每个目标站点都已加站。

2. 新品上架后建议尽快完成所有目标站点加站，避免遗漏导致部分站点无动销。

3. 加站后需确认SKU在该站点的在架状态，加站和在架是两个独立环节。

步骤3：查有没有被处罚

要查什么：确认商品是否存在违规处罚，导致商品被不让你卖、搜索排名往后排或强制下架。即使商品显示「在售」，违规处罚也可能导致商品被排名往后排，大幅减少曝光。

3.1 自查操作路径

操作步骤详细说明
Step 1：进入违规管理在商家后台导航至「违规管理」或「处罚记录」页面
部分业务模式下在「消息中心」-「违规通知」中查看
Step 2：查询商品违规输入商品ID（Goods ID / SKC ID / SKU ID）查询
也可通过店铺ID查询店铺下所有违规记录
建议按时间范围筛选（近30天/近90天）
Step 3：查看违规详情查看违规类型、违规原因、处罚措施、处罚状态
查看是否可申诉及申诉截止时间
记录违规编号，便于后续跟踪
Step 4：检查处罚影响确认处罚措施：强制下架/搜索排名往后排/限制上架/扣分等
确认处罚状态：已生效/已解除/申诉中
评估处罚对商品流量的影响程度

3.2 常见违规类型与处理方案

违规类型处罚措施常见原因（男装）处理方案
侵权违规下架+限制上架使用知名品牌LOGO/图案/款式仿冒；商标侵权；图片盗用确认侵权原因 → 删除侵权素材 → 更换原创设计/图片 → 重新提交审版
质量违规下架面料成分不符/做工缺陷/色牢度不达标/缩水变形严重提升产品质量 → 提供质检报告 → 申请复检或申诉
描述不符下架15天实物与图片/描述不一致（如色差大/版型不符/面料与描述不符）修正商品描述/图片/属性 → 确保与实物完全一致 → 提交修改审核
虚假宣传下架15天/直接下架夸大面料功能（如普通棉宣称为免烫/抗菌）虚标成分含量修改宣传内容 → 确保宣传内容真实准确 → 提交修改审核
图片违规驳回修改/下架图片含牛皮癣/水印/不适当内容/低俗暗示更换合规图片 → 确保图片符合平台规范 → 重新提交审版
Gcc美国站禁售皮衣/绒面非纯涤品 需要做gcc资质才能上美国看看面料是不是填写准确，准确的做一下gcc资质
重复铺货下架同店铺上同款/不同店铺但已经被系统判定同经营者上同款改款/下架同款
无违规记录无处罚商品无违规，继续下一步排查进入步骤4排查库存
📌 查有没有被处罚要点

1. 即使处罚已解除，之前的处罚记录可能仍影响搜索排名，建议多看几天。

2. 申诉有时效限制，收到处罚通知后请尽快处理，逾期可能不可申诉。

3. 男装品类重点关注：面料成分真实性、品牌侵权、尺码描述准确性。

步骤4：查有没有库存

要查什么：看看你的货仓里还有没有货。没货了买家下不了单，东西自然卖不动。货不够或者货不在卖的那个仓，都卖不了。

4.1 自查操作路径

操作步骤详细说明
Step 1：进入库存管理导航至「库存管理」或「库存中心」页面
确认进入全托管业务模式
Step 2：查询库存输入商品ID / SKC ID / SKU ID查询库存
也可通过店铺ID批量查询
选择正确的仓组进行查询
Step 3：分析库存数据查看各SKU的：可用库存、在途库存、总库存
可用库存 = 买家可下单购买的库存数量
在途库存 = 正在运输到仓的库存数量
Step 4：检查仓组分配确认库存所在的仓组
确认仓组是否覆盖目标销售站点
若库存未在目标站点仓组，需安排调拨或重新发货
Step 5：排查断货SKU统计可用库存为0的SKU数量
对于断货SKU，确认是否有在途库存预计到货时间
对于长期断货SKU，评估是否需要下架该SKU避免影响商品整体权重

4.2 库存状态判断标准

库存状态是不是卖不了判断标准处理方案
库存为0是 - 完全卖不了可用库存 = 0，无在途库存紧急补货 → 安排发货入仓 → 到货后恢复售卖；预计到货时间超7天的建议暂时下架SKU
库存极少部分卖不了可用库存偏低（根据日均销量判断）增加备货量 → 确保库存量（建议满足较长一段时间的预计销量）
有在途库存暂时卖不了可用库存=0但有在途库存确认预计到货时间 → 若7天内到货可等待 → 超过7天建议暂时下架
库存不在目标仓部分卖不了库存存在但不在目标站点仓组联系平台协调调拨 → 或重新发货到目标仓 → 确认仓组覆盖目标站点
库存充足否 - 正常可用库存充足（满足较长时间销量）进入步骤5排查商品图片与信息

步骤5：查商品图片和信息好不好

要查什么：看看商品图片拍得好不好、信息填得全不全。图片丑、信息少，买家点都不想点，更别说买了。

5.1 图片自查清单

检查项OK的标准
主图白底或场景图，清晰无水印，无牛皮癣，展示商品全貌
详情图有面料细节图、上身图、尺码图，多角度展示
图片比例符合平台要求，无变形裁切
图片数量建议6张以上（含主图+详情图）

5.2 商品信息自查清单

检查项OK的标准
标题包含品类词 + 风格词 + 材质词 + 场景词 + 卖点词
属性材质/版型/领型/袖长/适用季节等全部填写
尺码表完整提供，含肩宽/胸围/衣长/袖长，建议增加身高体重参考
描述与图片、属性一致，无夸大宣传

5.3 标题关键词参考

标题公式：品类词 + 风格词 + 材质词 + 场景词 + 卖点词

步骤6：查供货价贵不贵、价格有没有竞争力

要查什么：全托管模式下，商品售价由平台根据市场情况定价，商家主要通过供货价影响商品定价空间。排查重点是确认供货价是否有优化空间，以及商品前台售价在同类目中是否具有竞争力。若售价偏高，可通过降低供货价来间接影响前台定价。

7.3 商家能自己报名的活动、广告和增长工具（详细展开）

很多商家以为全托管模式下啥都只能等平台安排，其实不然。商家后台有不少活动、广告和增长工具是可以自己报名和设置的。下面把每一类能自己操作的工具详细列出来，照着做就行。

A. 活动报名（商家自己能报的）

操作位置：商家后台 →「活动管理」或「营销中心」→「活动报名」

活动类型是啥怎么报+有啥要求对卖货有啥用
秒杀活动限时限量打折，价格很低在活动报名入口找到秒杀活动 → 选商品 → 填活动价
要求：供货价要有优势，一般要低于日常价
要求：库存要够，不能活动中途断货
注意：秒杀价由平台审核，不是你填多少就多少		最快的方法搞出第一单
秒杀期间流量很大，曝光猛增
卖出去后能攒评价，后面自然搜索也能涨
适合：一直卖不动的货，用秒杀破零
折扣活动打折促销，力度没秒杀大在活动管理 → 折扣活动 → 选商品报名
要求：商品状态正常在售
要求：供货价合理，平台会根据供货价定折扣价
可以同时报多个商品一起做折扣		比秒杀温和，适合想冲量但又不想亏太多的货
折扣期间搜索排名会提升

要求：商品状态正常、库存充足
要求：供货价有竞争力，平台会筛选
注意：大促报名有截止时间，别错过		大促期间全平台流量最高

适合：所有正常在售的货都要尽量报
日常促销平时的常规促销位在营销中心 → 日常促销 → 报名参加
要求：商品在售且有库存
门槛比秒杀和大促低，容易通过		虽然没有大促流量大，但总比啥都不报强
适合：没赶上秒杀/大促的货，先报日常促销
📌 活动报名要注意的

1. 活动报名不一定都能通过，平台会筛选。

2. 同一个商品可以同时报不同类型的活动，但同一时间段只能参加一个活动（具体看平台规则）。

3. 报了活动一定要保证库存够！

4. 活动结束后要马上看效果数据，卖了多少、转化怎么样，为下次报名积累经验。

5. 活动报名入口不是一直开着的，要经常去后台看看有没有新活动可以报。

七、常见问题

Q1：商品状态显示「在售」，SKU也在架，为什么还是没有销量？
A：状态正常说明商品可以售卖，但无销量通常是因为：1) 商品图片质量差导致点击率低；2) 价格偏高缺乏竞争力；3) 未参与平台活动导致曝光不足；4) 商品未被搜索收录或排名靠后。请重点排查步骤5-7。
Q2：商品之前有动销，突然就没有了，是什么原因？
A：突然无动销常见原因：1) 库存断货（最常见）；2) 新增违规处罚导致排名往后排或下架；3) SKU被移出站点；4) 竞品大量低价涌入导致失去竞争力；建议优先排查步骤2-4。
Q3：男装新品上架后多少天有动销算正常？
A：通常新品上架后短时间内产生首单属于正常范围。若超过14天仍无动销，建议按这份指南查。若较长时间仍无动销，需重点排查图片质量和供货价竞争力。
Q4：商品图片已经很好了，还需要优化什么？
A：图片好但仍无动销，需排查：1) 标题关键词是否覆盖热搜词；2) 供货价是否有优化空间（全托管售价由平台定，降低供货价可间接影响前台售价）；3) 站内是否同款较多。图片自己觉得好不一定消费者认可，可以再用商品诊断去AI辅助看看有没有可以优化的空间。多个AI工具一起鉴别。
Q5：参与活动后还是没动销怎么办？
A：活动期间无动销需排查：1) 活动价是否仍然偏高，可考虑降低供货价；2) 秒杀流量比较大，可以考虑换秒杀+广告双开前期容易起量；3) 主图是不是表现一般；4) 活动期间是否有竞品以更低价竞争。
Q6：多个SKU中只有部分有动销，怎么办？
A：1) 看看好卖的SKU是什么颜色什么尺码，把不好卖的SKU信息也弄好；2) 看看是不是正常展示有没有部分SKU下架情况。本身站内的爆款搭配是黑白灰销量高，亮色图在欧美点击好，前期可以做黑白灰+一个亮色。如果拿不准啥颜色好卖联系对接运营。
Q7：修改后多久能看到效果？
A：不同修改类型的效果周期不同：库存补货 → 到货后恢复售卖；违规处理 → 申诉通过后恢复（一般找买手48h之内解罚没解开继续）；图片优化 → 数天到一周见效；供货价调整 → 平台调整前台售价后见效；活动参与 → 活动开始即见效；标题优化 → 一到两周见效。建议多盯几天看有没有效果。
Q8：如果排查完所有步骤还是找不到原因怎么办？
A：若所有维度排查均正常但仍无动销，建议：1) 找运营看店铺问题；2) 对比同类目动销商品的特征差异；3) 考虑商品是否存在市场需求不足的问题；4) 找运营看店铺问题；5) 找运营看店铺问题。

八、注意这几条

  • 这份指南适用于男装品类，其他品类也可以参考，但要根据自己卖的东西调整。
  • 查的时候建议一次多查几个多个商品ID，按店铺维度批量排查可大幅提升效率。
  • 若商品状态正常、SKU在架、无违规、有库存，但货还是卖不动，重点查第5-7步（图片、供货价、活动）。
  • 修改后建议持续观察一段时间，使用第六章的跟踪表记录数据变化，评估修改效果。
